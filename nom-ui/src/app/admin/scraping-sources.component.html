Only clear sources, sources with a written permission and facts-only sources approved for facts-only use are fetched. Every step below has a dry run and is undone by its stamp.

Classes recorded by hand

Record what a site's own words already say, so it is classed without a request to it: the class, the deciding words quoted, the page they stand on and the day you read them. It holds every row of the host (with and without www.) and a candidate or a host NOM has no row for yet. The source lane never changes it; a forbidden or permission-needed host is never fetched or checked and is excluded from every discovery run. It may be as strict as the class the check gave or stricter, never laxer, and clear only beside a recorded written permission. Undo it from its journal entry.
