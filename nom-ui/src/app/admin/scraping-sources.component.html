Source rights

Each source's class is derived by rule from its stored check: clear (a licence grants reuse), facts-only (nothing grants reuse, nothing forbids automated access), permission-needed (the terms could not be read or the site refuses automated fetches) or forbidden (the site's own words forbid automated access or reuse). Only clear sources, sources with a written permission and facts-only sources approved for facts-only use are fetched. Every step below has a dry run and is undone by its stamp.
